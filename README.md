# OpenBMC Lab 7 — CI/CD

Лабораторная работа 7. Настройка CI/CD с использованием GitHub, Jenkins и Docker.

## Pipeline

1. Запуск QEMU с OpenBMC.
2. Запуск автоматизированных тестов OpenBMC API.
3. Запуск WebUI-тестов.
4. Нагрузочное тестирование OpenBMC.
5. Сохранение отчётов в артефакты Jenkins.
